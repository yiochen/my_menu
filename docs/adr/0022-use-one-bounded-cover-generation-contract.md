# Use one bounded Cover-generation contract

Every Cover job uses one versioned server-owned template with Dish title, zero
to three selected Sources, every standalone Note, and enum-valued look, view,
and finish controls; no freeform visual prompt is exposed. Empty Sources support
context-grounded generation, while real Sources and appearance-relevant Notes
ground photo-based work without allowing Notes to control production style.
Every result must pass technical, safety, identity, and contradiction validation,
with a higher confidence threshold before automatic adoption.
