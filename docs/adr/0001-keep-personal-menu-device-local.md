# Keep the personal menu device-local

MyMenu will keep durable user-owned menu data on a single device rather than
replicating it to the server for backup or multi-device synchronization. This
reduces the amount of personal data entrusted to MyMenu and removes cloud sync
complexity, while deliberately accepting that uninstalling the app, clearing
its data, or losing the device can permanently lose the menu; user-controlled
export and import may be added separately.
