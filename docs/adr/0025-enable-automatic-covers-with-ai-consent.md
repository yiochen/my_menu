# Enable automatic Covers with AI consent

The versioned AI consent explicitly discloses and enables both organization and
default-on automatic Cover generation, including selected Sources, every Note,
automatic adoption, provider handling, and durable content-free usage metadata.
An independent setting may stop future automatic Covers without disabling
organization, but enabling it later never backfills existing Dishes. MyMenu
creates no Cover outbox entry or upload before current consent is accepted, and
older organization-only consent cannot authorize image generation.
