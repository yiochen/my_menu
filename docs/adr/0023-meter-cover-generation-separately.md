# Meter Cover generation separately

Organization and Cover allowances are independent so automatic imagery can
never disable capture grouping. A valid adopted automatic Cover or delivered
manual Proposed Cover consumes one Cover unit, while superseded correction
attempts, provider failures, validation rejection, and stale discarded results
record content-free zero-unit outcomes. Explicit manual work takes priority over
queued automatic work, and automatic generation may consume the last available
Cover unit.
